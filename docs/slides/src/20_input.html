输入

两种输入格式，一个精确到空格的约定

lab_txt：time,voltage

Scope export header Data,<-- 行末有一个 ASCII 空格 0.000000000000e+00,0.0123 1.176470588235e-12,0.0187 ... -1

解析器逐行读，直到遇到恰好等于 Data, （含尾随空格）的那一行，之后每行按第一个逗号切成时间与电压。

lab_csv：只有电压

Scope export header Data,<-- 同样含尾随空格 0.0123 0.0187 ... -1

没有时间轴 ⇒ 无法自行判断采样率 ⇒ 必须手动指定 --osr，否则报错而不是猜。

常见的坑

很多示波器导出是 Data,（无空格）或 Data , 。差一个字符就读不到数据；文件里出现的 -1 行是终止标记，会被跳过而不是当成数据。

OSR 判定

M（每 UI 采样数）从哪里来

人话

先量出「相邻采样点平均隔多久」，再用符号率换算：一个符号被切成了几段。

平均采样间隔t = median{ t[k+1] − t[k] },  0 ≤ k < Ns − 1
局部采样密度Mnative = 1 / (Rs · t)
整段平均密度Meffective = (Ns − 1) / [ Rs · (t[Ns−1] − t[0]) ]

自动模式接受条件（全部满足）

  • M_native 与 M_effective 取整后一致；
  • 取整误差 ≤ 10%；
  • M ≥ 2。

为什么不满足就报错？

两者不一致通常意味着：符号率填错、时间单位错（ns 当 s）、导出丢点、记录太短。猜一个 OSR，后面所有指标都失去意义，所以宁可直接失败。

丢点诊断

用 Δt / 平均间隔 的整数倍估计缺失采样比例，写进报告的 missing_sample_fraction。

重采样

落到均匀分析网格上

tgrid[k] = t[0] + k / (M · Rs),  k = 0 … Ngrid − 1
  • 带时间轴的波形用线性插值搬到这条网格上；
  • 只有电压的文件不做插值，直接按给定 OSR 解释；
  • 分析网格是「每 UI 恰好 M 个点」，后面所有矩阵推导都依赖这个前提。
注意

对带时间轴的数据手动指定 OSR 会强制使用该网格（等于重采样）。只有在明确知道自己在做什么时才这么做。

结果形状

y[k]：长度 N_s 的一维波形，之后被折叠成 M × N 矩阵。

同步

把本地码型「滑」到波形上：互相关对齐

人话

把歌词在录音上从左到右滑动，哪里最吻合，哪里就是起点。这里「滑动」是互相关，吻合程度是相关系数。

  1. 把符号序列按每符号重复 M 次上采样，得到与波形同速率的参考序列。
  2. 与实测波形做互相关，取 |相关| 最大的延迟作为对齐点。
  3. 若该峰为负，说明波形极性反了，自动整体翻转波形。
为什么用绝对值

差分探头或反相链路会让整条波形取负。用 |相关| 峰值可以先对齐、再判极性，而不是要求用户先猜对极性。

对齐微调

差一两个 UI？再搜一次

互相关给出的是采样级延迟，但拟合矩阵需要符号级对齐。做法是：

  1. 先用当前对齐做一次拟合，看 FFE 最大 tap 落在哪；
  2. 若没有落在期望的主 tap 位置（1-based 的 D_w + 1），依次尝试符号级移位 −2, −1, +1, +2 UI；
  3. 命中即停并记录 alignment_shift；全部失败则报错，不静默继续。
为什么不静默容错

错位的拟合会给出「看起来正常」但物理上无意义的脉冲与抽头。宁可失败并提示检查符号率/码型/极性。
