第一步

把长波形折叠成矩阵 Y

人话

把一条长录音按「每小节」剪开，一摞叠起来。第 m 行就是每个小节里的第 m 个采样点 —— 这样「同一相位」的样本排到同一行，方便逐相位比较。

折叠Y[m, n] = y[n·M + m]
取值范围0 ≤ m < M,  0 ≤ n < N
形状shape(Y) = M × N

M = 每 UI 采样数（行 = 相位），N = 参与拟合的符号数（列 = 第几个符号）。

第 n 列正是第 n 个符号周期内那 M 个采样点，顺序与波形一致。

# 代码落点 fit_pulse_response.py Y = data[:M*N].reshape(M, N, order='F') # 列优先 = MATLAB reshape

第二步

设计矩阵 X：每一行是「延迟 r 个 UI 的符号」

数据行X[r, n] = x[ mod(n + Dp − r, N) ],  0 ≤ r < Np
常数行X[Np, n] = 1  （吸收直流偏置）
形状shape(X) = (Np + 1) × N
  • r = 0 主光标，r < D_p 前游标，r > D_p 后游标；
  • 最后一行全 1：允许拟合出一个直流/共模偏移；
  • mod 循环移位：码型是周期的，末尾自然接回开头。
人话

这一行问「多少 UI 之前的那个符号」，那一列问「第几个时刻」。行 × 列就是「每个时刻、每个延迟位置上的符号值」。

# 代码落点 fit_pulse_response.py xr = concat(decisions[D_p:], decisions[:D_p])；X[r] = roll(xr, r)；X[N_p] = 1

第三步

三行推导：从代价函数到正规方程

模型Y ≈ P·X,   shape(P) = M × (Np + 1)
代价函数J(P) = ‖Y − PX‖F2 = tr[ (Y − PX)(Y − PX)ᵀ ]
求梯度∂J / ∂P = 2( PXXᵀ − YXᵀ )
令梯度为零P̂ = Y·Xᵀ·(X·Xᵀ)−1

这是标准最小二乘的正规方程解：把 N 个符号周期里所有相位的数据一起用上，对 N_p+1 个未知量做一次全局拟合。

形状检查（最实用的自查）

  • Y: M × N
  • Xᵀ: N × (N_p+1)
  • YXᵀ: M × (N_p+1)
  • XXᵀ: (N_p+1) × (N_p+1)
  • P̂: M × (N_p+1) ✓ 与第一项一致
人话

直觉上：把「每个相位、每个延迟位置」的贡献一次性解出来。矩阵乘法只是在替我们把 N 个方程同时最小化。

# 代码落点 fit_pulse_response.py P = (Y @ X.T) @ inv(X @ X.T) # 保持与 golden 相同的运算顺序

数值策略

为什么坚持显式求逆，而不是换伪逆

现在的做法

  • 显式写正规方程 P̂ = YXᵀ(XXᵀ)⁻¹；
  • 严格矩阵求逆，保持与参考实现相同的求解顺序；
  • XXᵀ 奇异时直接报错，不静默换成 pinv。

为什么

  • 可解释：结果与标准/参考工具一致，异常可追溯到具体参数；
  • 可复现：与 MATLAB golden 逐项对齐到 1e-9 量级；
  • 不掩盖问题：伪逆会给出「看起来能用」但物理无意义的脉冲与抽头。
失败即信号

奇异/病态通常意味着：符号率或码型填错、OSR 不对、拟合窗口太短、或 FFE tap 比脉冲约束还多。报错比给一个漂亮但错误的数字更有价值。

总设计原则：不猜测、不静默 fallback、不为了「跑通」而放宽语义

第四步

拟合波形、残差，以及「列优先」展开

拟合波形Ŷ = P̂·X
残差E = Ŷ − Y  （拟合值 − 实测值）
列优先展开p[r·M + m] = P̂[m, r],  0 ≤ m < M, 0 ≤ r < Np
e[k] = E 的列优先展开,  l[k] = Ŷ 的列优先展开

长度：p 为 M·N_p，e 与 l 为 M·N。

指标

脉冲的四组核心数字

稳态电压vf = 1M Σk p[k]
脉冲峰值pmax = maxk p[k]
峰值比rpeak = pmaxvf

v_f 是「把所有相位的脉冲加起来平均」，可理解为稳态幅度；理想情况下主峰附近的平均值应接近它。

残差 RMSeRMS,fit = √1|I80| Σk∈I80 e[k]2
拟合 SNDRSNDRfit[dB] = 20 log10 pmaxeRMS,fit

为什么要掐掉两端各 10%？

记录首尾常有采集窗、触发与循环移位造成的不连续。中央 80% 更能代表稳态拟合质量。

一个必须知道的实现细节

报告字段 eRms 保存的是主采样相位残差的中央 80% RMS；而 eRmsRatio 与 SNDR 用的是全速率残差 RMS。所以不能用报告里的 p_max / eRms 反算出同一个 SNDR —— 这是刻意保留的历史行为，不是 bug。

指标

残余 ISI：SNR_ISI 到底在量什么

主峰相位抽样ps[i] = p[ ipeak·M 处的采样 ]
峰值位置ipeak = arg maxi ps[i]
统计口径忽略主峰之后的前 10 个 post-cursor，只用其余尾部能量
SNRISI= 20 log10 ps[ipeak]√Σ ps[i]2, i = ipeak+11 … Np−1
  • 它只描述有限拟合窗口末端残余的 ISI，不是通用噪声 SNR；
  • 跳过 10 个 post-cursor 是为了不和 FFE/DFE 要处理的部分重复计分；
  • 窗口太短（i_peak + 11 > N_p）时该指标返回 NaN 并打印警告，而不是编一个数。
人话

前面的游标由 FFE/DFE 负责；SNR_ISI 关心的是「再往后那些没人管的小尾巴有多脏」。
