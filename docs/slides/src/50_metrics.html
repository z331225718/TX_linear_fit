星座 SNDR

逐相位均衡，再挑最好的那个相位

  1. 对每个相位 zz = 1…M，从波形里抽取 y[zz−1::M]（每 UI 取 1 点）；
  2. 用 FFE 系数滤波该序列，并去掉均值；
  3. 用阈值 slicer 得到硬判决（PAM4：±1/3、±1 四电平）；
  4. 若启用 DFE，按历史判决减去反馈量；
  5. 计算该相位的 SNDR = 20log₁₀( rms(判决) / rms(滤波 − 判决) )；
  6. 取 SNDR 最大的相位作为「最佳相位」，保存它的星座与波形。
人话

采样点落在 UI 里哪一个位置最「正中」，眼睛就张得最开。程序把每个可能位置都试一遍，挑最好的那个报告。

眼图重建

把 M 个相位重新交织成一张眼图

逐相位滤波产生 M 条序列；把它们放回原始采样顺序，就得到「均衡后」的连续波形，用于画眼图：

矩阵 A 形状 (L_max × M)： A[:, zz] = 第 zz 个相位的均衡输出 按行优先展开回一维： re_interleaved[(i)·M + zz] = A[i, zz]
移植时最容易错的一行

这一步在 MATLAB 参考实现里是行主序平铺（(zz−1)*cols + kk 且 zz 为行号）。若按列主序拼装，眼图与眼宽指标会整体错位 —— 本项目正是靠 golden 对比才发现并修正的。

RLM

台阶均匀不均匀：两种 RLM 定义

① 最小相邻间距 RLM_adj（字段 RLMbj）

阈值 −2/3, 0, +2/3 → 四组均值 V0…V3 d_L = V1 − V0 d_M = V2 − V1 d_U = V3 − V2 3 · min(d_L, d_M, d_U) RLM_adj = ───────────────────────── V3 − V0

报告名 RLM (Min Adjacent Spacing)；名字没有伪装成当前 IEEE 定义。

② IEEE 802.3bs / OIF CEI 定义（字段 RLMbs）

V_mid = ( V0 + V3 ) / 2 ES1 = ( V1 − V_mid ) / ( V0 − V_mid ) ES2 = ( V2 − V_mid ) / ( V3 − V_mid ) RLM = min( 3·ES1, 3·ES2, 2−3·ES1, 2−3·ES2 )

理想 PAM4 中 ES1 = ES2 = 1/3，四项都是 1 ⇒ RLM = 1。

一条有用的洞见

在通常的 0 ≤ ES ≤ 2/3 区间里，min(3ES, 2−3ES) = 1 − 3|ES − 1/3|。所以 IEEE 公式等价于「两个内层电平里，偏离理想位置最严重的那个决定 RLM」—— 向中间压缩和向外偏移都罚。这与只看三个相邻间距最小值的 RLM_adj 并不是同一个指标。

若某一电平没有样本，相应 RLM 记 n/a（例如 NRZ 或星座严重退化时），不编数。

SNDR

协议 SNDR 与工具 SNDR：一字之差

标准（OIF CEI-05.3 等）

p_max² SNDR_std[dB] = 10 log₁₀ ────────── σ_e² + σ_n²
  • σ_e：线性拟合误差的标准差；
  • σ_n：在规定条件下（如 ≥6 个相同符号连续区间、固定相位）单独测得的噪声；
  • 功率相加 ⇒ 用 10 log₁₀。

本工具

p_max² SNDR_fit[dB] = 10 log₁₀ ─────────── e_RMS,fit²
  • 不单独测 σ_n；
  • 用中央 80% 残差 RMS 代替完整测量流程；
  • 只有 σ_n = 0 且 e_RMS,fit = σ_e 时两式才等价。
汇报时请注意

报告不套用协议 SNDR 限值。CLI 另输出的 SNDR ffe / SNDR ffe_and_dfe 是均衡后判决域指标（分子/分母/滤波/判决都不同），不能与 SNDR (Fit) 横向比较；为避免误读，这两个值不出现在 HTML 报告里。

频域

测量派生传递函数：从脉冲反推频响

① 造理想脉冲 p_ideal：幅度 max|p|、宽 1 UI、 上升/下降时间 1 fs（数值上近似理想方波） ② P(f) = DFT{ p[k] } P_ideal(f) = DFT{ p_ideal[k] } ③ H̃(f) = |P(f)| / |P_ideal(f)| H(f) = H̃(f) / H̃(0), H(0) = 1 ④ Nyquist : H_Nq[dB] = 20 log₁₀ |H(R_s/2)| ⑤ BW 3dB : 第一个满足 20log₁₀|H(f)| ≤ −3 的频点

理想脉冲频谱的零点会让分母趋零，程序先剔除近零频点再线性插值补回分母。

别叫它插损

H(f) 同时包含发送端、采集链路与有限拟合窗口的影响，不是混合模 S 参数 S_DD21，不能替代协议规定的通道插入损耗。数值为正表示相对 DC 有高频提升（boost），不应称为「正的损耗」。

眼宽

95% 与 99% 眼宽：为什么不能只数过零点

① 相邻样本异号时线性插值求过零相位： φ[i] = mod( k − y[k] / (y[k+1] − y[k]), M ) ② 圆均值求 crossing 中心： φ_mean = [M/2π]·arg{ Σ exp( j·2π·φ[i]/M ) } ③ 展开到 [−M/2, M/2)： δ[i] = mod( φ[i] − φ_mean + M/2, M ) − M/2 ④ 取分位点（默认中央 99%）： Δ = Q_0.995{δ} − Q_0.005{δ} W = clip( 1 − Δ/M, 0, 1 ) [UI]

53.125 GBd 时 1 UI ≈ 18.824 ps；4 ps ≈ 0.2125 UI。

人话

如果只找「最窄的那一秒」，那么成千上万个 UI 里只要有一次抖动毛刺，眼宽就会塌成 0。中央 99% 的意思是：把最外侧各 0.5% 的过零点当离群点排除，剩下的跨度才算眼宽。
