目标

什么叫「均衡成功」：脉冲变成一根针

人话

理想情况下，一个符号只应该在自己那一格产生影响。但通道把能量拖到了前后几格。均衡器就是一排「反向砝码」，把拖出去的能量抵消掉，让结果回到一根针的样子。

目标向量xp[ Dp + 1 ] = 1  （1-based，主 tap 位置）
其余元素= 0
FFE 问题ŵ = arg minw ‖ P3·w − xp ‖22

也就是说：找到 N_w 个系数，使脉冲卷积它们之后，最接近一个单位冲激。

注意：这是分析侧逆滤波器。GUI 默认 18 tap 表示「用 18 个系数看可恢复性」，不代表 DUT 硬件真有 18 个 tap。

归一化

两种归一化，别混用

FFE-only：Σw = 1

wnorm[i] = ŵ[i]Σj ŵ[j]

只保证直流增益为 1，不限制单个系数幅度。对应字段 firNumNorm，用于画 Equalized Eye。

FFE+DFE：Σ|w| = 1

wnorm[i] = ŵ[i]Σj |ŵ[j]|

按 L1 归一，对应字段 firNumDFENorm；FFE+DFE 分支主要用于 RLM 诊断。

常见误读

归一化不会把系数限制在 ±1。如果正负 tap 相互抵消使 Σŵ 很小，某个归一化 tap 完全可能远大于 1。这不是越界或自动饱和，而是无硬件约束的逆滤波结果；系数过大通常意味着噪声增强、脉冲窗口不足，或通道有难以逆转的深衰减。

人话

除以 Σw 是「保持总增益不变」；除以 Σ|w| 是「保持总能量不变」。就像调音量 vs 调总输出功率，两者不是一回事。

DFE

DFE：把前几个后游标「交给判决反馈」

新目标xp[Dp + j] = ps[ipeak + j]ps[ipeak]   j = 1 … NDFE
同时作为DFE 抽头权重 DFEtapWeight
硬判决â[n] = Q( zFFE[n] )
反馈减法zafter_DFE[n] = zFFE[n] − Σj b[j]·â[n−j]
人话

FFE 是「事前」补偿：在判决前把波形整形。DFE 是「事后」补偿：既然前面的符号已经判出来了，就按它的电平把当前样本里残留的影响直接减掉。

指标归属

HTML 报告里的 Equalized Eye Diagram 用的是 FFE-only 波形；FFE+DFE 的结果主要用于 RLM 诊断 —— 两者不能互相替代比较。

故障诊断

Singular matrix：四类原因与参数约束

为什么会奇异

  • total_cursor_ffe > total_cursor_fit：未知量比约束还多；
  • PRBS、符号率、OSR 或同步设置错误 → 拟合脉冲退化；
  • 脉冲窗口太短，重要前后游标落在窗口外；
  • 通道零点或高度相关的列使 P3ᵀP3 病态。
参数约束0 ≤ Dp
Dp + NDFE < Np
0 ≤ Dw < Nw ≤ Np
Nw ≤ Np  （否则必然奇异）

程序怎么处理

  • 先强制 total_cursor_fit ≥ total_cursor_ffe；
  • 数据仍不足满秩时，报告矩阵秩并要求增大 pulse fit 窗口或减少 FFE tap；
  • 绝不悄悄改用伪逆给一个「表面可用」的结果。
