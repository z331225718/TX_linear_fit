CLI

两条命令覆盖两类输入

# ① 带时间轴（OSR 自动推断）—— 推荐 python python_src/run_tx_linear_fit.py --filetype lab_txt --filename "C:/path/to/Waveform.txt" --symbol_rate 53.125e9 --modulation PAM4 --prbs_pattern PRBS13 --pattern_length 8191 --pre_cursor_fit 4 --total_cursor_fit 32 --pre_cursor_ffe 4 --total_cursor_ffe 18 --dfe_tap_num 1 --output-dir outputs/run # ② 只有电压（必须显式指定 OSR） python python_src/run_tx_linear_fit.py --filetype lab_csv --filename "C:/path/to/Waveform.csv" --osr 16 --symbol_rate 53.125e9 --modulation PAM4 --prbs_pattern PRBS13 --pattern_length 8191 --pre_cursor_fit 4 --total_cursor_fit 32 --pre_cursor_ffe 4 --total_cursor_ffe 18 --dfe_tap_num 1 --output-dir outputs/run

参数之间的关系

0 ≤ Dp
Dp + NDFE < Np
0 ≤ Dw < Nw ≤ Np

选择建议

  • pre_cursor_fit 覆盖可见前游标；total_cursor_fit 覆盖主要 pulse tail；
  • tap 不是越多越好：过长会让逆滤波追逐噪声；
  • 要复现协议条款，先按目标接口设 N_p, D_p 与采集滤波器，再谈限值。

GUI

五步跑完一次分析

  1. 选择输入文件（.txt / .csv）与输出目录；
  2. 填符号率（默认 53.125 GBd，是 symbol rate，不是 PAM4 比特率）；
  3. 选 NRZ/PAM4 与 PRBS7/13/15（自动使用完整周期长度）；
  4. 带时间轴的 txt 保持 OSR「自动」；只有电压的 csv 切「手动」；
  5. 按需调整 pulse fit / FFE / DFE tap 数，点「开始分析」，默认生成并打开报告。

延伸阅读

想深挖，从这里开始

  • IEEE Std 802.3-2022 —— 以太网基础标准与修订入口：standards.ieee.org/ieee/802.3/10422/
  • IEEE P802.3bs PAM4 TX linearity / RLM 材料（给出 V_mid、ES1、ES2 与 RLM 公式）：ieee802.org/3/bs/public/16_03/healey_3bs_02_0316.pdf
  • IEEE P802.3ck TX SNDR 背景（p_max、σ_e、σ_n 结构）：ieee802.org/3/ck/public/adhoc/oct02_19/diminico_3ck_adhoc_100219.pdf
  • OIF-CEI-05.3 —— 矩阵拟合与 FFE（10.3.1.6.4-5）、Gray mapping / QPRBS13-CEI / RLM（16.C.1、16.C.3、16.C.4.3）、CEI-112G XSR/MR/LR（24/26/27.3.1.6）
提醒

标准条款与限值会随修订变化；任务组材料不是标准正文。正式测试应查阅目标标准的当前完整文本，并以目标 PHY、测试点与规定滤波器为准。

与本材料的对应关系

公式、符号与边界描述均与仓库内 docs/TECHNICAL_GUIDE.md 一致；本材料是它的教学版：补了类比、图示、代码落点与排障清单。

总结

一页纸记忆卡

流程六步

  1. 定 OSR：相邻采样间隔中位数 → M_native / M_effective，一致且 ≥2 才接受
  2. 重采样到 t = t0 + k/(M·R_s)
  3. 再生 PRBS + Gray 映射，xcorr 对齐（负峰翻极性）
  4. 折叠 Y + 设计 X → P̂ = YXᵀ(XXᵀ)⁻¹
  5. 由 P3 解 FFE，注入 DFE 目标
  6. 出指标与图：SNDR / RLM / TF / 眼宽

三条纪律

  • 不猜：OSR、极性、参数约束不满足就报错；
  • 不掩盖：奇异不用伪逆糊过去，差异登记为 known deviation；
  • 可验证：同一份波形 + golden 逐字段比对，1e-9 才算过。
最后一句话

这套算法的本质只有一句：用已知的符号序列，把未知的脉冲响应「解」出来，再据此设计均衡器并量化剩余损伤。
